What the two GKE runs actually cost, from the resource-level billing
export rather than from the console. Queried on 13 October 2026, a day
after the second run, which is long enough for a day's usage to settle.

Table: moyo-cloud-lab.billing_export.gcp_billing_export_resource_v1_01614A_44C4CF_9E48D3
All figures USD. "net" is cost after credits, which is what gets charged.


THE QUERY
---------

bq query --use_legacy_sql=false '
SELECT
  DATE(usage_start_time, "Europe/London") AS day,
  sku.description AS sku,
  ROUND(SUM(cost), 4) AS cost,
  ROUND(SUM(cost) + SUM(IFNULL((SELECT SUM(c.amount) FROM UNNEST(credits) c), 0)), 4) AS net
FROM `moyo-cloud-lab.billing_export.gcp_billing_export_resource_v1_01614A_44C4CF_9E48D3`
WHERE DATE(usage_start_time, "Europe/London") BETWEEN "<from>" AND "<to>"
  AND project.id = "moyo-cloud-lab"
  AND cost > 0
GROUP BY day, sku
ORDER BY day, net DESC'

READING THE DIFFERENCE
----------------------

2.8 times the September run, and the SKU split separates the two
causes without needing a price list.

Balanced PD capacity and the external IP charge are both per hour, and
both runs had the same two VMs and the same 110GB of disk: two 50GB
boot disks and Loki's 10GB. Those two lines rose 1.7x and 1.9x, so
that is the difference in how long the cluster was up. The October
cluster ran 2h42, which puts September at roughly an hour and a half.

vCPU and RAM both rose 3.4x. Divide out the runtime and about 1.9x is
left, which is the per node-hour difference between e2-standard-2 and
e2-medium. So the node size change that made room for Argo CD roughly
doubled the hourly rate, and the longer session accounts for the rest.

The non-spot E2 lines at a tenth of a penny are the node pool briefly
running on-demand instances during creation, before the spot
allocation took over. Present in both runs.


WHY THIS FILE EXISTS
--------------------

The README used to say the September run billed $0.05 with a $0.08
management fee. The export says $0.1520 and $0.2528. The old numbers
were read off the billing console on the day of the run, when usage
had not finished posting, and were never checked afterwards.

A cost figure quoted the same day is an estimate. This one is the
invoice.
